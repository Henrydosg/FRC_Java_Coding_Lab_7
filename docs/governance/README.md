The seven rules are binding only through root AGENTS' exact path/scope incorporations. Root controls conflicts pending HOLD and Architect reconciliation; rules cannot contradict authoritative English Documents A/B/C. A link, index or filename confers no additional authority.

LEARNING_FLOW_MAP does not authorize curriculum changes. History preserves evidence and consumed permissions. migration/ preserves design, review and decision provenance; its pre-cutover candidates and stage-specific gate wording are not current authority. Root README is project/student navigation and directs current-state questions to CURRENT_STATE.

The migration sequence remains G0 design → G1 registration → G2 recovery/scope → G3 skeletons → G4 population → G5 coverage → G6 independent review → G7 authorized cutover → G8 separate post-cutover review → G9 User Git publication → G10 external verification. Consult CURRENT_STATE for the actual stage and authorized action; this navigation does not execute or authorize a gate.
