## Active evidence contract

Verification results retain PASS, FAIL, NOT TESTED and NOT APPLICABLE meaning; N/A requires genuine applicability, not absent evidence. Classifications identify WHAT was verified, BY WHOM, against WHICH snapshot, WHEN and within WHAT limits.

| Classification | Required meaning |
| --- | --- |
| THEORY VERIFIED | Supported theory/static architecture conclusion within inspected scope |
| SOFTWARE TEST VERIFIED | Identified software assertions passed through accepted execution; no physical proof |
| BUILD VERIFIED | Accepted executed build result for the identified snapshot; not presumed from compilation or cache alone |
| SIMULATION VERIFIED | Accepted Simulation scope; distinguish GUI/runtime from deterministic adapter tests |
| GLASS VERIFIED | Accepted visualization/inspection scope |
| DRIVER STATION VERIFIED | Accepted mode/control/connection scope |
| REAL HARDWARE VERIFIED | Accepted physical execution within stated devices/conditions/measurements |
| REAL HARDWARE DEFERRED | Explicitly approved physical deferral; no hardware PASS implied |
| NOT APPLICABLE | Verified applicability judgment, not a substitute for NOT TESTED |

The applicable M00 student-facing vocabulary remains the five labels in the source bilingual/evidence family below. Software/build/Glass/DS facts can be separately described as supporting evidence without changing that module-specific normative vocabulary.

Keep verified hardware identity, unknown assumptions, provisional settings and final verified tuning distinct. Noop requested state and invalid zero are not measurements of hardware. Builds/tests/Simulation do not prove physical stop, homing, game-piece transfer, travel margins, endpoint accuracy, calibration or final gains. Freshness, rerun/cache behavior, provenance and source snapshot matter; preserve accepted historical limits rather than invent fresh execution.

Hashes prove byte identity, not semantic fidelity. A configured validator PASS proves only its deterministic checks. Semantic coverage, authority equivalence, bilingual meaning and sufficient evidence require human/Architect review. Cutover asserts no new semantic-fidelity certification.
